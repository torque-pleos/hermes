# Hermes 디자인

## 원칙 (Pleos Connect UI Design Guide 기준)

| Pleos 원칙 | Hermes 적용 |
| --- | --- |
| Glanceability 1~2초 | 주행 화면 3줄: 다음 정차·도착 시각 / 가는 길 최대 강수(큰 색 블록)·시각·근거 / 이후 구간 |
| 대비 4.5:1 이상 | 주간·야간 토큰 모두 본문 텍스트를 배경 대비 4.5:1 이상으로 지정 |
| 중요 정보 텍스트 5mm 이상 | 주행 화면 핵심 44sp, 보조도 24sp 이상. 홈 본문 20sp, 캡션 18sp |
| 자동 스크롤·애니메이션 금지 | 주행 화면에 스크롤·애니메이션·입력 없음 |
| Landscape·Portrait 모두 지원 | 앱 폭 1000dp 초과 시 2열(브리핑 62% · 근거 38%), 이하(1:1 분할 창 등) 1열 스크롤 |
| 주간/야간 모드 | 시스템 야간 모드를 따라 `IviColors` 두 벌 전환 |
| 아이콘 + 텍스트 라벨 | 강수 색 블록 옆에 항상 단계 텍스트, 범례 표시. "예보 없음"은 색이 아니라 빗금 무늬로 구분 |
| 디자인 토큰 `ivi_` 접두·snake case | `ui/theme/HermesTheme.kt`의 `IviColors`(예: `ivi_surface_card`, `ivi_rain_heavy`), `IviType`, `IviSpace` |
| 큰 터치 영역 | 버튼 최소 높이 64dp |

## 화면 구조 (차량용 터치 UI)

왼쪽 **내비게이션 레일**(운전석 쪽, 폭 132dp, 항목 높이 112dp, 큰 아이콘 + 라벨): 브리핑 · 경로 · 차량 공유 · 진단.
차량 공유 항목에는 비를 본 주변 차량 수 배지.

| 화면 | 구성 | 터치 |
| --- | --- | --- |
| **브리핑** | 큰 결론 카드(강수 아이콘 112dp, 52sp 제목, 구간, 근거 배지) → 숫자 타일 3개(다음 정차 · 비구름 이동 · 주변 차량) → 경로 강수 띠 + 범례 → 출처 | 결론 카드 → 해당 구간 정차지 상세, 타일 → 경로/차량 공유, 띠 → 경로 |
| **경로** | 목록-상세: 정차지 카드(최소 120dp, 번호·이름·도착 시각·도착 시 강수 아이콘) / 상세(도착 시 강수 88dp 아이콘·근거, 가는 길 표본별 강수 막대, 비구름 이동) | 카드를 눌러 선택 |
| **차량 공유** | 주변 차량 수(52sp)·단계별 수, 공유 동의 큰 스위치(줄 전체 터치), 내 와이퍼, 판단 방식 3줄, 시연 버튼 | 스위치·시연 버튼 |
| **진단** | 개발·시연용 SDK 상태, "주행 화면 미리보기" | — |
| **주행 중** | `CarUxRestrictions` DO 필요 시 자동 전환. 다음 정차·도착 시각 / 가는 길 최대 강수(아이콘 112dp)·근거 / 이후 구간 | 없음(입력·스크롤·애니메이션 금지) |

## 터치·피드백

- 모든 터치 대상 최소 76dp(버튼), 카드·레일은 112~168dp. 터치 대상 사이 간격 16dp 이상.
- 누르는 동안 살짝 축소(0.97) + 리플 + 진동 피드백 — **주차 중 화면에만**. 주행 화면은 정적.
- 넓은 창(900dp 초과)은 2~3열, 좁은 창(1:1 분할 등)은 1열 스크롤.

## 강수 아이콘

구름 + 빗방울 개수로 단계를 표현(약 1 · 보통 2 · 강 3 · 매우 강 4), 비 없음은 구름 + 체크, 예보 없음은 흐린 구름.
색과 **모양**을 함께 써서 색각 이상·흑백에서도 구분된다. 직접 그린 벡터(사내 아이콘 자산 미사용).
탭·버튼 아이콘 6개(Dashboard, Route, Groups, Tune, Navigation, CloudUpload)는 Material Icons Rounded(Apache 2.0) 경로 데이터를
`ui/HermesIcons.kt`에 옮겨 쓴다. 아이콘 확장 라이브러리 전체를 넣으면 디버그 APK가 88MB → 제거 후 47MB.

## 강수 색

없음(초록 계열) → 약한 비(파랑) → 보통 비(노랑) → 강한 비(주황) → 매우 강한 비(빨강). 기상청 강도 구분과 같은 4단계 + 없음. 예보 없음은 빗금.
