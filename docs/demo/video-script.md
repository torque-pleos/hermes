# Hermes 시연 영상 대본

- 목표 길이: 약 2분 10초 (말하는 속도 기준 분당 약 300음절)
- 말투: 원고를 읽지 말고 심사위원 앞에서 직접 시연하듯이. `/`는 짧게 쉬기, **굵은 글씨**는 살짝 힘주기.
- 녹음: 장면마다 파일 하나씩 (`H01_오프닝.m4a` …). 틀리면 그 장면만 다시 녹음.
- 범위: 구현·검증된 기능만 (강수 레이더 예측, 정차지 도착 시각 강수, 와이퍼 차량 공유, 주행 화면). F1 운행 전 점검·F5 상하차 타이밍·F6 관제는 구현 전이라 넣지 않았다. 구현되면 H06 앞에 장면을 추가한다.

## 녹화 메모

- 에뮬레이터 `emulator-5554` + Virtual Console `:8088`. 다른 Pleos 에뮬레이터를 같이 띄우면 Virtual Console이 `emulator_inactive`가 되니 녹화 중엔 5554만 켠다.
- 터치 위치 표시: `adb -s emulator-5554 shell settings put system show_touches 1`
- 실제 강수는 녹화 시점 날씨에 따라 다르다. 맑은 날이면 H03에서 "가는 길에 비 소식 없음"이 나오므로, 비가 있는 날 녹화하거나 H05 시연 버튼(가상 차량 비 관측)으로 비 장면을 만든 뒤 H03을 다시 찍는다.
- H04 그래프는 `docs/verification/hindcast-2026-11-01-1240Z.md` 수치로 만든다.
- 출처 표기 필수: "기상청 단기예보(저작자표시)", "RainViewer", 지도 사용 시 "© OpenStreetMap contributors".
- 레이더 첫 로딩 약 20초 → 녹화 전에 미리 띄워 둔다.
- 화면 속 시각·대수(06:12, 4대 등)는 예시다. 실제 녹화 값이 달라도 대사에는 숫자가 없어 그대로 쓴다.
- 비구름이 적은 날은 이동 신뢰도가 낮아(예: 4%) "참고용"이 붙는다. H04는 비가 넓게 있는 날 찍거나 그림·그래프 비중을 늘린다.
